# 0.0.0-draft
Public draft for a local test Raspberry Pi. Not a release. Do not use it on a station you rely on.
- The application installs from https://github.com/eckirchn/BirdNET-Pi
- Identification stays the official BirdNET method: https://birdnet.cornell.edu/ and https://github.com/birdnet-team
- The recognizer and model files are unchanged
- 64-bit Raspberry Pi OS is required. 32-bit Pi OS will not install
